# 06 · WebUI 设计

> v0.2 更新：导航信息架构对齐"项目 → 功能 → 对话"层级（03 §1）；新增 §5 自然语言操作层（评审意见 4：用户不止可以通过页面操作，也可以通过自然语言操作页面）。

## 1. 设计原则

1. **突出必要信息**：任何页面首屏只回答一个核心问题（Dashboard：项目健康吗？功能页：这块推进到哪了？对话：现在轮到谁、发生了什么？）；
2. **功能收纳而非堆叠**：低频/高级功能压缩进 ①左侧图标任务栏 ②右键菜单 ③⌘K 命令面板 ④详情抽屉，**不占主区域**；
3. **渐进披露**：新手路径 ≤3 次点击完成核心闭环；专家通过快捷键/命令面板直达深水区；提示词上下文同样按层披露（03 §2）；
4. **同源多视图**：看板/列表/图/对话共享同一数据与 URL 参数，切换零成本；
5. **人机无差别呈现**：卡片不因执行者是 Agent 而特殊化，只用小徽标区分（🤖/👤）；
6. **双通道操作**：一切可见操作既可点击完成，也可一句话完成（NL 与 UI 同构，见 §5）。

## 5. 自然语言操作层（NL as UI，v0.2 新增）

**定位**：页面操作的第二通道。规则只有一条——**页面上每个可见操作，都能被一句话完成**；因为两者调用同一组 REST API，NL 层只是"意图 → API 调用"的翻译器。

### 5.1 交互形态

```
⌘K 命令栏
 ├ 命令模式（默认）：模糊搜索动作/对象，回车执行（v0.1 已有）
 └ 自然语言模式（Tab 切换或直接输入整句）：
    "把看板切到 v0.2，只看 dev-agent 的卡，T7 T8 指派给我"
      ↓ UI-Agent 解析为 3 个动作
    [✓ 切换里程碑过滤 v0.2]              ← 只读，直接执行
    [✓ 过滤 assignee=dev-agent]          ← 只读，直接执行
    [▸ 指派 T7,T8 → 李雷] [确认] [取消]   ← 写操作，预览+确认
      ↓ 执行后气泡回显
    ✓ 已完成 3 项操作 · [撤销] [查看事件]
```

### 5.2 UI-Agent 设计

| 要素 | 设计 |
| --- | --- |
| 模型 | 小模型即可（意图解析任务），可独立于执行 Agent 的模型配置 |
| 工具集 | = 前端可用的全部应用 API（导航/过滤/选择/批量审批/指派/启动/打断…），注册为带 schema 的工具 |
| 上下文注入 | 当前页面状态（当前视图、可见对象、选中项）+ 项目本体实体词典（08：概念/状态/关系名皆可解析） |
| 安全分级 | 与工具权限同构：只读动作直接执行；写动作预览+确认；dangerous（删除/发布）预览+二次确认，**永不静默执行** |
| 审计 | 每次执行落 `ui_command.executed` 事件（actor=ui-agent，on_behalf_of=user，含原文与解析结果），可撤销（事件回滚） |
| 失败处理 | 解析不出 → 提示候选动作列表让用户点选（降级为命令模式），不猜 |

### 5.3 能力分级（MVP 只做第一级）

| 级别 | 能力 | 例句 | 版本 |
| --- | --- | --- | --- |
| L1 视图与批量 | 导航/过滤/选择/批量审批 | "只看高优先级的 bug"、"批量批准 PRD 相关的" | MVP |
| L2 对象操作 | 指派/启动/打断/建卡建对话 | "T7 指派给 dev-agent 并启动"、"打断正在跑的对话" | V1.3 |
| L3 复合意图 | 多步规划+参数推导 | "把导入功能里没动过的任务都排到下个里程碑" | V2 |
| 语音输入 | 话筒按钮 → 同管道 | — | V2（可选） |

### 5.4 与对话体系的关系

NL 操作默认不产生持久对话（轻量、即用即走），但每次执行的**原文+解析+结果**都进事件流可审计；用户可把某次 NL 操作「固定为对话」以便追问与迭代（升级为操作型对话，03 §1）。

## 6. 交互与工程细节（v0.1 保留，微调）

- **URL 即状态**：视图/过滤/选中项/当前功能编码进 query，可分享可回退；
- **实时**：SSE 全局单连接，按 project/feature 分发；对话流式、看板移动、审批出现均增量更新；
- **乐观更新 + 事件回执校正**（事件溯源下天然一致）；
- **空状态**：每页有"下一步"引导（功能页空 → 「从一句话开始，PM-Agent 帮你拆任务」）；
- **性能预算**：首屏 < 2s；对话虚拟滚动（超长消息树）；甘特超 500 span 自动折叠；
- **可访问性**：键盘全操作、焦点环、对比度 AA；i18n 文案键（默认 zh-CN）。

## 7. a11y 机械锁与浏览器扫描双防线（M89-I270 新增）

jsdom 下的 axe 锁（M85 第七件机械防腐）对**布局依赖规则结构性失明**（color-contrast 等 jsdom 无布局不可评——M85/M89 两次实证）；浏览器级扫描是这些规则的唯一测量面。双防线：

1. **jsdom 锁**（自动化，vitest）：`a11y.test.tsx` Modal/Drawer 代表性内容零 serious/critical + 故意红自证；规则裁剪仅页面级 region/landmark/heading。
2. **浏览器扫描**（人工门，发布轮/大改样式后 ~15 分钟）：隔离双端口（如 8142/4181·seed 造数）→ `pnpm build && cp web/node_modules/axe-core/axe.min.js web/dist/` → `pnpm preview --port 4181` → 浏览器控制台注入 axe（`fetch('/axe.min.js')`+eval）→ 逐路由 `axe.run(document, {rules: {region/landmark-one-main/page-has-heading-one: enabled:false}})`。**复扫前必须注销 SW + 清 caches**（`navigator.serviceWorker.getRegistrations()` 逐一 unregister——precache 会供旧 bundle 让 axe 扫旧产物，M89 实证）；主题切换后重扫须等 >`transition-colors` 0.15s 过渡（中途取样是伪影，M89 实证）；**每次 goto 后 axe 可能被整页导航抹掉须重注入**（M90 实证）；**单页加载后等 ≥2.5s 再扫，flag 须重扫复核**（react-query 数据落地前的一闪状态会产生瞬态伪影——M90 两例均重扫即消失·三连验证法）。

**M89-I270 基线 + M90-I273 全路由闭环**：M89 修复前六路由 critical 18（表单可访问名）+ serious 80（color-contrast×72 等）→ token 级修复后亮暗双主题全 clean。M90 补扫剩余路由再清 23 处（risks 评分字 opacity-70×9 与概率/影响 select、ontology 三个 date input 与成员/角色 select 与代理人 title-only、activity 空文本链接×2[系统事件无项目名→链接空文本·修法=兜底文本「（未命名项目）」]与过滤 select×2、audit/my-work select 各 1）→ **24 路由（App 路由全集并集·intake 占位/错误态除外）×亮暗双主题终扫全 clean**。token 级修复面：五个前景色升档（acc #6366f1→#4f46e5 / ag #8b5cf6→#7c3aed / ok #059669→#047857 / warn #d97706→#b45309 / dan #dc2626→#b91c1c——500 档在白/浅底上 3.07~4.46:1 不达 AA 4.5:1）+ 新增 `--color-acc-hover`（亮 #4338ca/暗 #a5b4fc——primary 按钮 hover 态双主题 7:1+）+ primary 系文字 `text-white`→`text-accbg`（暗色 acc 上白字 2.98:1 → accbg 4.84:1）+ 顶栏 replay 徽标 zinc-500→zinc-400 + 排程非当月格去整格 `opacity-45`（文字被拖到 1.78:1）改底色弱化 `bg-bg/40`。暗色组核算原全过未动。**纪律**：新增页面必须进终扫清单；新增前景色一律色板 600/700 档+双主题复扫；`text-white on bg-acc` 类组合禁止（用 text-accbg）。
